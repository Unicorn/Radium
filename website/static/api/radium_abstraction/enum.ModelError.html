Expand description

Represents an error that can occur when interacting with an AI model.

Variants§

§

RequestError(String)

An error occurred during the API request (e.g., network issues, invalid request).

§

ModelResponseError(String)

The model returned an error (e.g., invalid input, rate limiting).

§

SerializationError(String)

An error occurred during serialization or deserialization.

§

UnsupportedModelProvider(String)

The model provider is not supported or configured.

§

QuotaExceeded

Provider quota exceeded or rate limit hit (hard stop error).

Fields

§provider: String

The provider name (e.g., “openai”, “gemini”).

§message: Option<String>

Optional error message from the provider.

§

ContentFiltered

Content was filtered/blocked by the provider’s safety system.

Fields

§provider: String

The provider name (e.g., “openai”, “gemini”).

§reason: String

Reason for filtering.

§safety_ratings: Option<Vec<SafetyRating>>

Safety ratings that caused the filtering (optional).

§

UnsupportedContentType

The model does not support the requested content block type.

Fields

§content_type: String

The content block type that is not supported (e.g., “audio”, “video”).

§model: String

The model ID that does not support this content type.

§

UnsupportedMimeType

Unsupported MIME type for multimodal content (provider-specific validation).

Fields

§mime_type: String

The MIME type that is not supported.

§supported_types: Vec<String>

List of supported MIME types for the current provider.

§

InvalidMediaSource

Invalid media source (file path doesn’t exist, URL is malformed, etc.).

Fields

§media_source: String

The media source that is invalid (file path or URL).

§reason: String

Reason why the source is invalid.

§

MediaSizeLimitExceeded

Media content exceeds the model’s size limit.

Fields

§size: usize

The actual size in bytes.

§limit: usize

The maximum allowed size in bytes.

§media_type: String

The media type (e.g., “image”, “audio”).

§

InvalidMediaFormat

Invalid media format (MIME type not supported).

Fields

§format: String

The MIME type that was provided.

§expected: String

List of expected MIME types (formatted as comma-separated string).

§

ContentTooLarge

Content too large for inline transmission (multimodal validation).

Fields

§actual_size: usize

The actual size in bytes (after base64 encoding if applicable).

§max_size: usize

The maximum allowed size in bytes.

§content_type: String

The content type/MIME type.

§

InvalidContentFormat

Invalid content format (corrupted or malformed file).

Fields

§content_type: String

The content type that failed validation.

§reason: String

Reason why the format is invalid.

§

InvalidFileUri

Invalid file URI (malformed or unsupported scheme).

Fields

§uri: String

The file URI that is invalid.

§reason: String

Reason why the URI is invalid.

§

Other(String)

Other unexpected errors.
