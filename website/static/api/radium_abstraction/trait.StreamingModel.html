fn generate_stream<'life0, 'life1, 'async_trait>( &'life0 self, prompt: &'life1 str, parameters: Option<ModelParameters>, ) -> Pin<Box<dyn Future<Output = Result<Pin<Box<dyn Stream<Item = Result<StreamItem, ModelError>> + Send>>, ModelError>> + Send + 'async_trait>>
where Self: 'async_trait, 'life0: 'async_trait, 'life1: 'async_trait,

Generates a streaming text completion based on the given prompt.

Returns an async stream that yields stream items as they’re generated by the model. Each item in the stream is a Result<StreamItem, ModelError> where:

  • Ok(StreamItem::ThinkingToken(token)) contains a token from the thinking process
  • Ok(StreamItem::AnswerToken(token)) contains a token from the final answer
  • Ok(StreamItem::Metadata(map)) contains metadata updates
  • Err(error) indicates an error during generation

For non-thinking models, all tokens will be AnswerToken.

§Arguments
  • prompt - The input prompt for text generation
  • parameters - Optional parameters to control generation (including reasoning_effort)
§Returns

A pinned, boxed stream of stream items. The stream must be Send to allow use across async boundaries.

§Errors

Returns a ModelError if the stream cannot be created (e.g., connection failure, invalid request). Errors during streaming are yielded as items in the stream itself.
